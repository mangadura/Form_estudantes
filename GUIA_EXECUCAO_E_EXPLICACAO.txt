1. O QUE VEM NESTE PACOTE (.ZIP)

Main.java: É o código do programa da escola pronto e sem erros (funciona em praticamente qualquer versão do Java instalada no PC).

relatorio.txt: Um arquivo de bloco de notas comum que o próprio programa cria sozinho (na opção 6), já preenchido com 5 alunos inventados de exemplo.

GUIA_EXECUCAO_E_EXPLICACAO.txt: Este texto explicativo que você está lendo agora.

2. COMO LIGAR O PROGRAMA NO COMPUTADOR

Pelo jeito mais fácil: Abra o arquivo Main.java no programa que você usa para programar (VS Code, IntelliJ, Eclipse ou NetBeans) e clique no botão de "Play" (Run).

Pela tela preta (Terminal / Prompt): Abra o terminal dentro da pasta onde está o arquivo, digite os dois comandos abaixo (apertando Enter depois de cada um):javac -encoding UTF-8 Main.java (prepara o código)java Main (liga o programa)

3. O QUE CADA PARTE DO CÓDIGO FAZ (SEM TERMOS DIFÍCEIS)

Classes, objetos, atributos e construtores: É o molde da ficha do aluno. A classe Aluno é a ficha em branco (com espaço para nome, turma e duas notas). Cada vez que você cadastra alguém, o código preenche uma ficha nova dessas.

Variáveis e tipos de dados: São as "caixinhas" onde o programa guarda as informações:

String: guarda textos (nomes, turmas).

int: guarda números inteiros (opções do menu, quantidade de alunos).

double: guarda números quebrados com vírgula (notas e médias).

Métodos, parâmetros e return: São mini-tarefas prontas para o código não precisar repetir conta. Você entrega as notas para o método, ele calcula a média e devolve (return) o resultado pronto.

Estruturas condicionais (if, else): São as decisões do programa ("Se" e "Senão"). Exemplo: se a média for 6 ou mais, escreve "Aprovado"; senão, escreve "Recuperação". Também serve para barrar notas erradas (menores que 0 ou maiores que 10) e avisar se a lista estiver vazia.

Estruturas de repetição (for, for-each): É quando o programa precisa fazer a mesma tarefa várias vezes seguidas sem parar — como passar de aluno em aluno para mostrar todo mundo na tela ou somar a nota da turma inteira.

Arrays e ArrayList: São as listas onde os alunos ficam guardados enquanto o programa está aberto. O ArrayList é uma lista elástica que cresce sozinha conforme você adiciona alunos; o Aluno[] é uma lista de tamanho fixo usada na opção 6 para montar o relatório.

equalsIgnoreCase(): É um filtro para o programa entender que "Maria", "maria" e "MARIA" são a mesma pessoa quando você busca, edita ou apaga alguém.

Operações com listas (add, remove, get, size): São os comandos básicos para mexer na lista: add coloca um aluno novo, remove apaga, get pega um aluno específico pela posição e size conta quantos alunos existem ao todo.

Leitura e escrita de arquivos (java.io): É a parte que salva tudo no computador para não sumir quando você fechar o programa. Ele cria o arquivo relatorio.txt, escreve os dados lá dentro e depois consegue ler esse mesmo arquivo para mostrar na tela.
